# 🛡️ Noxian Shots - Photography & Videography Web App

Isang responsive at dynamic na web application para sa Noxian Shots booking at portfolio showcase.

## 🌟 Features
* **Portfolio Showcase:** Gallery ng mga larawan at video.
* **Service Packages:** Dynamic listing ng mga alok na serbisyo at presyo.
* **Booking System:** Client inquiry at booking form na may real-time local storage integration.
* **Admin Control Panel:** Management dashboard para sa mga bookings, media, packages, at payment methods.

## 🛠️ Tech Stack
* HTML5 / CSS3
* Vanilla JavaScript (ES6)
* LocalStorage API
